# 受渡連動 Power-Up(ステップ1)

ボード上部の「受渡連動」ボタンから、Trello連携と連動のON/OFFを切り替えるところまでです。
カードを動かす処理は、ステップ2・3で追加します。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | Trelloが読み込むコネクタ |
| client.js | ボタンの定義 |
| settings.html | ボタンを押したときの設定画面(連携、ON/OFF) |
| config.js | APIキーの設定 |
| icon.svg | ボタンのアイコン |

## 手順

1. **公開する**: 6ファイルを同じフォルダにまとめて、GitHub Pagesなど https で公開します。
2. **Power-Upを登録する**: https://trello.com/power-ups/admin → 新規作成。
   - 名前: 受渡連動
   - iframeコネクタURL: 公開した index.html のURL
3. **機能を有効にする**: 登録画面の「機能」で「Board Buttons」にチェックを入れて保存します。
4. **APIキーを作る**: 登録画面の「APIキー」で新しいキーを発行します。
   - 「許可されたオリジン」に、公開したURLのオリジン(例: `https://ユーザー名.github.io`)を追加します。
   - 発行したキーを、config.js の `appKey` に貼ります。
5. **ボードで有効にする**: 対象ボードの「パワーアップ」から「受渡連動」を追加します。
6. **動作を確認する**: 「受渡連動」ボタン → 「Trelloと連携する」 → 「連動をONにする」。ボタンの表示が「受渡連動 ON」に変われば成功です。

## 確認してほしい点

- 「Trelloと連携する」でエラーが出る場合は、許可されたオリジンの設定を確認してください。
- ONの状態は、ボードに保存されます(共有データ)。ほかのメンバーにも同じ状態で見えます。
